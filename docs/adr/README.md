# ADR-001 — Domain First

**Status:** Accepted

**Date:** 2026-08-01

## Context

Business concepts outlive technology.

## Decision

The Domain Blueprint governs implementation.

## Alternatives Considered

- Technology First
- Data Model First
- Domain First (Selected)

## Consequences

### Positive

- Stable business language
- Technology independence

### Negative

- Higher initial modeling effort
