# ADR-010 — Domain Blueprint as Source of Truth

**Status:** Accepted

**Date:** 2026-08-01

## Context

Business knowledge often becomes fragmented across code and documents.

## Decision

The Domain Blueprint is the authoritative reference for the business domain.

## Alternatives Considered

- Tighter runtime coupling
- Shared database
- Selected approach

## Consequences

### Positive

- Shared understanding
- Traceable decisions

### Negative

- Documentation must evolve with the code
