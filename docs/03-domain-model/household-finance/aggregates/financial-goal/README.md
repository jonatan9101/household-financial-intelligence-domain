# FinancialGoal

> Aggregate responsible for defining and tracking long-term financial objectives.

## Purpose

A FinancialGoal represents a measurable objective owned by a Household, such as building an emergency fund or saving for a vacation.

Progress is calculated by read models from FinancialMovement events.

## Responsibilities

- Define goals
- Manage lifecycle
- Protect target invariants
- Publish goal events

## Out of Scope

- Move money
- Calculate savings
- Investment management
- Forecasting
